# VK-web-course-1sem
Сайт запускается с помощью команды: docker compose up --build

Далее нужно перейти в браузере по адреcу http://localhostL:8000


Сайт состоит из нескольких страниц:

1. основная страница(адрес: "/")

2. страница тега(адрес "/tag/philosophy")

3. страница вопроса(адрес "/question/34")

4. страница настроек(адрес "/settings")

5. страница входа(адрес "/login")

7. страница регистрации(адрес "/register")

8. страница создания вопроса(адрес "/newQuestion")
